# Cisco Networking Projects

This repository contains a collection of Cisco Packet Tracer labs, networking exercises, and configuration projects completed during my undergraduate studies at Universitas Sriwijaya. The projects cover fundamental network configuration, IPv4 addressing and subnetting, LAN connectivity, inter-LAN routing, multi-router network topologies, and dynamic and static routing protocols, including RIP and OSPF. Each project is documented through its original Packet Tracer file, providing practical examples of network design, device configuration, and connectivity testing.
